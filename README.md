# PLACE

A surreal psychological horror game currently prototyped in Python,
with plans for a future 3D remake in Godot.

## About

PLACE is a text-based game where the player finds themselves
somewhere they don't recognize.

Question the Guide. Make choices. Pay attention.

Not everything you hear is telling you the truth.

## Features

- Branching dialogue
- Multiple choices
- ASCII animations
- Sound effects
- Color-coded dialogue
- Different voices and messages
- Surreal horror atmosphere

## Built with

- Python
- Tkinter
- Colorama
- PyFiglet
- Playsound
- PyTTSX3

## Color guide

🟣 Magenta &rarr; PLACE \
🔵 Cyan &rarr; choices / interaction \
🟡 Yellow &rarr; player's dialogue \
🔴 Red &rarr; danger / errors / warnings \
⚪ White &rarr; narration
