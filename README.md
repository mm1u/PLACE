# PLACE
A surreal text-based horror game written in Python.

## Color guide

> [!IMPORTANT]
> **Magenta** &rarr; PLACE

> [!TIP]
> **Cyan** &rarr; choices / interaction

> [!WARNING]
> **Yellow** &rarr; player's dialogue

> [!CAUTION]
> **Red** &rarr; danger / errors / warnings

> [!NOTE]
> **White** &rarr; narration
